# 🏋️ Ashish Fitness Zone — Support Center

A dark-themed, fully responsive **gym support/help center** website — built to give members a fast, self-service way to find answers on memberships, billing, bookings, and access, without needing to call in.

## 🔗 Live Demo
[View Live Site](https://musical-entremet-1a35f0.netlify.app/)

## ✨ Features
- **Live System Status** — real-time-style cards showing status of payments, app/portal, class booking, and gym access
- **Smart Search Bar** — jumps straight to the FAQ section based on user query
- **Browse by Topic** — 6 categorized help topics (Memberships, Billing, Bookings, Access, Account, Facilities) with article counts
- **FAQ Accordion** — expandable Q&A covering cancellations, billing disputes, guest passes, PT bookings, keycard issues, and payment updates
- **Contact Section** — 4 support channels (live chat, email, phone, in-person) plus a working contact form
- **Support Hours Widget** — weekly hours table with the current day auto-highlighted
- **Fully Responsive** — clean layout across desktop and mobile

## 🛠️ Tech Stack
HTML • CSS (custom properties/theming) • Vanilla JavaScript

## 🚀 What I Learned
- Structuring a multi-section single-page layout with sticky navigation
- Building interactive UI (accordion, live search-to-scroll) without a framework
- Using CSS custom properties for a consistent dark theme across components
